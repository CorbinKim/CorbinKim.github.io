## The core equation

Scaled dot-product attention computes a weighted sum of value vectors, where the weight assigned to each value depends on the dot product of the query with the corresponding key:

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

The $\sqrt{d_k}$ term matters: without it, dot products grow large in magnitude as $d_k$ increases, pushing the softmax into regions with extremely small gradients.

## A minimal implementation

```python
import numpy as np

def attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)
    weights = np.exp(scores) / np.exp(scores).sum(axis=-1, keepdims=True)
    return weights @ V
```

## Complexity at a glance

| Component        | Time complexity      | Space complexity |
| ----------------- | --------------------- | ------------------ |
| $QK^\top$          | $O(n^2 d_k)$           | $O(n^2)$            |
| softmax            | $O(n^2)$               | $O(n^2)$            |
| weighted sum       | $O(n^2 d_v)$           | $O(n d_v)$          |

The quadratic dependence on sequence length $n$ is the well-known bottleneck that later work (linear attention, FlashAttention, etc.) tries to address.
